VindereaMasinii
Un program util în C# pentru calcularea prețului de vânzare al unei mașini, luând în calcul investițiile suplimentare și profitul dorit.

Ce face programul:
Input preț achiziție: Cere utilizatorului suma cu care a cumpărat mașina.

Calcul accesorii: Întreabă care a fost costul total pentru accesorii sau modificări.

Aplicare coeficient: Folosește un coeficient (multiplicator) pentru a calcula prețul final de vânzare, astfel încât să rezulte un profit.

Rezultat: Afișează suma totală pe care trebuie să o ceri pe mașină.

Logica programului:
Se citește prețul mașinii și al accesoriilor.

Se face suma lor: total_investit = pret_masina + pret_accesorii.

Se aplică coeficientul de profit: pret_vanzare = total_investit * coeficient.

Tehnologii folosite:
C# / .NET 8.0

Variabile de tip double sau float pentru calcule precise cu bani.
